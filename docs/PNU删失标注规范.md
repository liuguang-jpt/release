# P/N/删失标注规范（150 条人工标注校准版）

版本：v2.0（**v1.0 已废弃，原因见 §7 修订历史**）
日期：2026-08-16（§5 阈值依据 150 条人工标注校准，见 [[ANNOTATION_REVIEW]]）

## 1. 目标

本规范用于统一PROTAC降解终点中活性证据、观测类型和证据质量的标注。三者必须分别记录，不能压缩为一个标签。

## 2. 活性证据

- P：有充分证据支持有效降解（**任一强信号即可**：DC50≤100nM 或 Dmax≥70%）。
- N：有明确低/无效降解证据（**任一强信号即可**：DC50≥1000nM 或 Dmax≤20%）。
- A（ambiguous）：证据矛盾、临界或信息不足（双信号冲突、区间跨阈值、有观测但不触发）。
- U（目标终点无可用观测）：**不要把 U 当 0/负类**；录入错误数据（如 Dmax=2000）归 U。

在确定阈值之前，先保留连续值和不等号，不要只保存二分类标签。

## 3. 观测类型

- exact：精确数值。
- left-censored：仅知道小于某阈值（DC50 `< X` → pDC50 下界）。
- right-censored：仅知道大于某阈值（DC50 `> X` → pDC50 上界）。
- interval-censored：仅知道处于某一区间。
- endpoint-missing：该终点缺失。

## 4. DC50/pDC50换算

若DC50单位为nM，精确值换算：`pDC50 = 9 - log10(DC50_nM)`。

不等号方向会反转：
- `DC50 > 1000 nM` → `pDC50 < 6`；
- `DC50 < 10 nM` → `pDC50 > 8`。

## 5. 定稿规则（v2.0，2026-08-16，OR 逻辑，150 条一致率 94.7%）

### 5.1 DC50 阈值（nM）
- P 候选：DC50 ≤ **100 nM**；
- N 候选：DC50 ≥ **1000 nM**（= 10×P 阈值）；
- 阈值敏感性扫描档位：50 / 100 / 300 / 1000 nM（P），N = 10×P。

### 5.2 Dmax 阈值（%）
- P 候选：Dmax ≥ **70%**；
- N 候选：Dmax ≤ **20%**；
- 敏感性档位：Dmax_P ∈ {70, 80}，Dmax_N ∈ {10, 20}。

### 5.3 联合规则（OR 逻辑：任一强信号即判定）
- **任一终点触发 P 信号**（DC50≤100 或 Dmax≥70）→ **P**（即使另一终点有观测但不达标；人类标注证实：Dmax 极强 >90% 时单终点足以判 P）；
- **任一终点触发 N 信号**（DC50≥1000 或 Dmax≤20）→ **N**（同理，DC50>10000 时单终点足以判 N）；
- **P 信号与 N 信号同时触发**（双终点方向相反）→ **A**（证据矛盾）；
- 两终点皆缺 → **U**；
- 有观测但均不触发信号 → **A**；
- 删失/区间值触发规则同 exact（`DC50>X` 且 X≥1000 → N 信号；`DC50<X` 且 X≤100 → P 信号；区间整体落入阈值内 → 信号；跨阈值 → 不触发）。

#### 5.3.1 为什么是"任一信号 OR"而不是"双终点一致优先"？（联合逻辑校准论证）

两个终点各自独立触发信号后如何合并，曾有两种候选逻辑：

| 逻辑 | 规则 | 直觉 |
|---|---|---|
| 任一信号 OR | 任一端点触发信号即判定 | 强证据说了算 |
| 双终点一致优先 | 两端点必须一致才判定，单终点达标→A | 多证据一致才可靠 |

**150 条人工标注裁决：OR 逻辑一致率 94.7%，双终点一致仅 82.7%**——"双终点一致"的直觉（更谨慎=更可靠）被数据证伪。逐条诊断（见 [[ANNOTATION_REVIEW]] §4）揭示人类专家的真实判断模式是"**任一强信号充分性**"（sufficiency of any strong signal）：

1. **Dmax 极强、DC50 一般 → 人类判 P**：
   `DC50=230, Dmax=>95`；`DC50=469, Dmax=100`；`DC50=630, Dmax=94`——Dmax 能降解 90%+ 就是强降解剂，DC50 在灰色区只是"信息不足"，不是"反对证据"。双终点一致把这些全误判为 A。
2. **DC50 极弱、Dmax 一般 → 人类判 N**：
   `DC50=>20000, Dmax=30`；`DC50=>20000, Dmax=49`——20000nM 下仍无强降解就是无效分子，Dmax 未触发 N 信号（>20）不影响结论。
3. **双信号冲突 → 两种逻辑都判 A**（一致，无分歧）：
   `DC50=50000（N 信号）, Dmax=101（P 信号）`——真正矛盾的证据，OR 逻辑同样判 A。

**原理**：DC50 与 Dmax 的触发阈值本身已是保守的高标准（100nM 是纳摩尔级高效力线、70% 是近满降解线）。**一个终点跨过这么高的门槛，其本身就是充分证据**；另一终点处于灰色区不等于"反对"，把"信息不足"当作"证据不足"去否定已有强信号，是过度保守的方向性错误。

**OR 逻辑的边界**（不是无脑 OR）：
- 弱信号触发不了（灰色区 DC50 100–1000nM、Dmax 20–70% 均不触发）；
- P/N 冲突 → A（证据矛盾才是"证据分级"的用武之地）；
- 剩余不可表达的 8 条分歧（5.3%）为"单信号极强 + 另一信号差一点"的边界案例（如 `DC50=10, Dmax=68`，人工判 A），纯阈值规则无法覆盖，需人工复核或更细的 P1/P2/P3 分级。

**论文表述**：证据分级体系设计中，人类专家遵循"任一强证据充分性"而非"双证据一致性"——该结论由 150 条独立人工标注校准得出（OR 94.7% vs 双终点一致 82.7%），可作为 Methods 中标签规则构建的方法学依据。

### 5.4 数据质量防护（单终点失效，不整体判 U）
- **Dmax > 150% 或 < 0%** → 该终点视为无效（不参与信号），其余终点正常判定；
  - 依据（脏值溯源，见 [[ANNOTATION_REVIEW]] §5）：Dmax 101–112 为文献原文的 Western blot 量化波动（真实强降解），**保留**；Dmax=2000 为数据库录入错误（assay 描述与靶点矛盾、无 DOI），防护；
- **DC50 ≤ 0** → 该终点视为无效（"未检出"被编码为 0 的转录问题），Dmax 正常判定；
- 重复测量取首值（v0.1 约定），长剂量序列 Dmax 取最大值；冲突标记保留原始串。

### 5.5 待定事项（下轮标注前需决策）
- 不同处理时间如何处理：暂不聚合，按记录保留；
- 不同细胞系：视为不同实验条件，不合并；
- 专利/图中读取数据的证据权重：低一档（建议 confidence 上限"中"）。

## 6. 试标记录与歧义日志

每遇到一种新情况，记录：原始文本、初始判断、最终判断、理由、是否需要修改规范。

150 条标注中 10 条与系统 provisional 分歧（全部为边界/单终点不一致案例），明细见 [[ANNOTATION_REVIEW]] §3；其中 1 条为系统解析错误（Dmax=2000% 脏值判 P → 人工判 U），已由 5.4 防护规则覆盖。
