## 已完成的人工流程

1. `protac_annotation_150.csv` 包含 150/150 条开发/校准标注。
2. 132 条内部一致性样本由两名标注角色独立填写，再由第一作者按冻结 v2.0 规则裁定分歧。
3. 该流程用于评估协议和规则的一致性，不是独立专家金标准，也不是外部验证。

## 分层抽样概览
- 主分层：`dc50_obs_type`(5) × `activity_evidence`(P/N/A/U) → 20 cell。
- 稀有记号保底：interval≥12 / left≥18 / right≥18 / endpoint-missing≥20 / exact≈82。
- 覆盖确认：5 类 obs 记号齐全；P/N/A/U 四态齐全；E3（CRBN/VHL/other）、Top-5 POI（ERalpha/BRD4/BTK/AR/Tau）均有代表。
- 复现：`code/sample_annotation_150.py`（seed=20260815，可复现）。

## 冻结判据（v2.0）
- **P**：充分证据支持有效降解（如 DC50≤100 nM 或 Dmax≥80% 且条件充分）。
- **N**：明确低/无效降解证据（如 DC50≥1000 nM 或 Dmax≤10%）。
- **A**：矛盾/临界/信息不足（边界值、单终点、区间跨阈值）。
- **U**：两定量终点皆缺，无任何可用观测（**不要把 U 当 0/负类**）。
